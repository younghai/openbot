1.요약

'개인 AI 팀원' 생태계는 2025~26년에 폭발적으로 성숙했다. OpenClaw(39.3만★)가 게이트웨이 + 20여 개 메신저 채널 + 플러그인 마켓(ClawHub)의 사실상 표준을 만들었고, orca(10.9만★)는 여러 에이전트를 관리하는 플릿 계층으로 부상했다. rakazo가 나열한 경쟁 제품 — Meta Muse, OpenAI Dots, Claude Duet, Hermes Agent — 은 모두 실존이 확인됐고 각각의 자체호스팅 대체재도 존재한다.

우리 OpenBot은 컴퓨터 격리 · 도구 게이트+감사 · 위임/서브에이전트 · 루틴 · MCP 소스 · 스킬 등 플랫폼 뼈대는 상위권과 이미 겹친다. 비어 있는 것은 이 생태계가 증명한 핵심 가치 3가지다: ① 어디서나 만나는 채널(메신저), ② 진짜 기억(시맨틱 메모리), ③ 진짜 목소리(WebRTC 대화). 본 보고서는 이 갭을 메우는 9건의 적용 제안을 우선순위(즉시 3 / 단기 3 / 중기 3)와 함께 제시한다.

4.OpenBot 현재 상태와 3대 갭

보유 플랫폼 뼈대

  • 영속 봇 · 대화 · 루틴(cron) · FIFO 큐
  • Team/Private 컴퓨터 격리 (local·docker·e2b 등 6종)
  • 도구 게이트웨이 + 감사 로그 (SSRF 차단 실측)
  • peer 위임 / 서브에이전트, 공유 채널
  • MCP·OpenAPI·Composio·Pipedream 툴 소스
  • Playwright 대화형 브라우저, 스킬, 컨텍스트 압축

갭 1 채널

봇이 웹 UI에서만 만날 수 있다. 메신저 게이트웨이 없음 — OpenClaw가 증명한 핵심 가치 "이미 쓰는 채널에서 만남"이 비어 있다.

갭 2 기억

메모리 검색이 SQL LIKE다. "커피 좋아함"을 "마실 것 취향?"이라는 다른 표현으로 회수하지 못한다.

갭 3 목소리

통화 모드가 밀기-대화(push-to-talk)다. 끼어들기가 없고 한 사이클(녹음→전사→응답→TTS)이 순차 실행된다.

5.적용 제안 — 즉시 (저비용 · 고가치)

TIER 1 · 즉시오늘 구현 가능, 매트릭스 검증 포함

① browser-use를 MCP 툴 소스로 연결 노력 小

현재: 저수준 browser.open/click/type를 모델이 한 땀 한 땀 (호출 5~10회)→적용 후: "예약해줘" 과제를 browser-use 에이전트에 통째로 위임

폼 작성·로그인 세션 유지·캡차 상황을 browser-use가 자체 처리한다. 복잡 웹 작업의 성공률·속도 상승, 메인 모델 토큰 소모 절감. 기존 mcp.ts 재사용이라 연결만으로 붙는다. 주의: browser-use 자체가 LLM을 호출 — 키가 없으면 ③ Ollama와 조합해 완전 로컬로 운영.

② MCP 공식 서버 카탈로그 프리셋 노력 小

현재: MCP 엔드포인트 URL을 직접 찾아 입력→적용 후: GitHub·파일시스템·검색 등 공식 서버 목록에서 원클릭 연결

순수 사용성 개선. 봇이 "GitHub 이슈 읽기" 같은 도구를 갖게 되는 진입 장벽이 사라진다.

③ Ollama 로컬 모델 노력 零 · 문서만

현재: 클라우드 키가 없어 모든 봇이 mock 응답→적용 후: base_url=localhost:11434/v1 지정 즉시 실제 모델로 전환

BYO 프로바이더가 이미 호환된다(코드 0줄). 비용 0원 · 외부 전송 0 · 완전 로컬. 이 머신에서 실제 모델을 쓰는 유일한 무료 경로. 로컬 모델 성능은 클라우드 대비 열세이고 메모리 제약이 있다.

6.적용 제안 — 단기 (1~2주 규모)

TIER 2 · 단기게이트웨이/계층 교체 수준의 개발

④ Telegram 채널 게이트웨이 노력 中

현재: 봇과 대화하려면 웹 UI를 직접 열어야 함→텔레그램에서 문자로 대화 + 루틴 결과가 푸시 알림으로 도착

봇이 "브라우저 안의 웹앱"에서 "주머니 속 연락상대"로 바뀐다. long-polling이라 공인 IP·포트 없이 이 Mac에서 동작, 봇 토큰 무료. 감사·큐·루틴은 기존 체계 그대로 공유. OpenClaw식 채널 확장(WhatsApp·Slack 등 20+)의 첫 단계.

⑤ mem0 OSS로 메모리 계층 교체 노력 中

현재: LIKE 검색 — 단어가 다르면 기억 회수 실패→시맨틱+키워드+엔티티 하이브리드 — 다른 표현으로도 상기

"아이스 아메리카노 좋아한다고 했었지"가 "마실 것 취향?" 질문에도 회수된다. 기억 누적 정리와 시간 추론(과거/현재 구분) 포함. 주의: 임베딩 모델(OpenAI 키 또는 Ollama 임베딩) + Qdrant 벡터 DB 필요.

⑥ 도구 승인 큐 (allow/ask/deny + 수신함) 노력 中

현재: 정책 통과한 도구는 사람 개입 없이 즉시 실행→위험 도구는 사람이 승인/거절할 때까지 대기 (Inbox)

invisible_dots가 증명한 패턴. 거절 사유가 봇에게 전달된다. ④ 텔레그램·루틴과 결합하면 무인 운영 봇의 파괴적 행동을 사람이 게이트키퍼로 차단 — 기존 감사 게이트의 자연 확장이며 다중 사용자 확장 시 필수 안전장치.

8.시너지 조합과 라이선스 주의

③+① 완전 로컬 에이전트

Ollama + browser-use = 키 없이 로컬 모델이 로컬 브라우저를 조종하는 폐쇄 회로.

④+⑥ 안전한 원격 지시

텔레그램 + 승인 큐 = 밖에서 봇에게 시키되 위험 행동은 사람 승인 후 실행.

⑤+⑧ 기억과 가시성

시맨틱 메모리가 쌓일수록 사용량/헬스 대시보드의 관리 가치가 커진다.

라이선스 주의 — open-webui · lobehub(lobe-chat) · n8n은 커스텀/fair-code 라이선스(실측 NOASSERTION)다. 코드 반입은 피하고 패턴만 참고할 것. LibreChat(46.4천★, MIT)은 안전한 참고 대상이다.
