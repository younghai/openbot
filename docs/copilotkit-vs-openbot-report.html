1. 총평 — 점수표

종합
우리 88 vs CopilotKit 93 (100점 만점, 항목 가중 평균)

한 문장 요약: 우리는 "1인용 완성도"에서 근접(승인·감사·보안·도구 폭은 동급 또는 우세)하고, CopilotKit은 "조직 제품 완성도"에서 압승(다중 사용자·AG-UI 버스·배포 인프라). 품질 축(테스트·문서)은 이들이 앞서고, 아키텍처 축(경량성·무키)은 우리가 앞선다.

2. Computer Use 실측 비교 — 오늘 우리 머신에서 직접 돌려본 결과

실측 1: 채팅에서 "example.com 읽어와서 제목 알려줘" → browser.fetch 18초에 성공, 봇이 "제목은 Example Domain입니다" 정답. 승인 0회(allow 정책).
실측 2: "openpage — 브라우저로 열어줘" → browser.open이 실제 Chromium 기동, 승인 큐 거친 뒤 스크린샷이 채팅에 인라인 렌더.
실측 3: agent-desktop 1.1.0 설치 확인, macOS accessibility granted — 네이티브 데스크톱 스냅샷/act 경로 유효.
실측 4(구현 후 재측정, 2026-11-15): 라이브 화면 스트리밍 구현·실측 완료(WS jpeg, "연결됨"), 제어권 이관 구현·실측 완료(승인→act 프록시→반납→byPerson), 브라우저 프로필 영속 구현·실측 완료(PROFILE:none→persisted-ok), 시크릿 직주입 구현·실측 완료(봇 미노출). 남은 것: 라이브 터미널 스트리밍, Recorder.

결론: 도구 "실행 능력"은 대등하나, "보면서 신뢰"와 "막힌 곳 사람에게 넘기기"가 빠져 있다. 이 둘이 CopilotKit 컴퓨터유즈 체험의 핵심이다.

4. 아키텍처 비교

우리 — 단일 프로세스 무키

React 18 (Vite, PWA)→ Hono :8940 (6 deps)→ node:sqlite WAL
  • 에이전트 루프·게이트웨이·큐·루틴·채널 전부 한 프로세스
  • 도구 39종이 같은 executeTool 단일 관문(승인→체크포인트→감사)
  • 컴퓨터 = 로컬 워크스페이스+Seatbelt / agent-desktop
  • 백업 = 파일 복사 한 장. 복구 5초
  • 약점: 확장은 "더 큰 머신"뿐 — 레플리카·분산 개념 없음

CopilotKit — 서비스 분해 조직용

app :3010→ server :3001→ AG-UI 런타임→ agent-* 420x
  • Postgres(감사·정책·큐) + Intelligence(스레드·메모리·학습) 외부
  • 컴퓨터=독립 컨테이너(supervisor :4500가 생성, 서버 토큰 안 줌, 이그레스 프록시)
  • OpenAPI 3.1 스펙→클라이언트 자동생성, Idempotency-Key, problem+json
  • LISTEN/NOTIFY로 레플리카 동기, work_items skip-locked 큐
  • 약점: 설치 무게(7서비스+Intelligence), 클라우드 의존 구간
게이트웨이 철학은 같다 — "컴퓨터는 정책을 판단하지 않는다, 서버 관문이 판단한다". 우리도 CK도 승인→감사→실행 3단. 차이는 표현력: CK는 CEL 규칙+initiator 서명 어서션까지, 우리는 도구×정책+스코프 허용까지.

6. 우리가 부족한 것 — 추가 제안 (우선순위)

P0 — 컴퓨터유즈 격차 해소 (체험 품질 최대 격차)

  • 🅐 라이브 브라우저 패널 — Playwright 페이지를 WS로 프레임 캡처(jpeg 2-4fps)해 채팅 옆에 스트리밍. 승인 대기 중에도 화면이 보이면 신뢰가 생긴다. 기반: 이미 있는 ws.ts + browser.open 세션. 공수 1-2일
  • 🅑 제어권 이관 (takeover) — computer.request_help 도구: 봇이 호출하면 승인 카드가 "사람이 직접" 모드로 전환 → 라이브 패널에서 키보드·마우스 CDP 바인딩 → 완료 버튼 → 봇 재개. CAPTCHA·로그인의 유일한 정상 탈출로. 공수 2-3일. CK의 computer_request_help + 시크릿 마스크 박스(computer_request_secret)까지 벤치마크
  • 🅒 브라우저 세션 영속 — userDataDir을 워크스페이스 아래 고정해 로그인·쿠키가 봇별로 남게. "매번 다시 로그인" 제거. 공수 반나절

P1 — 감사·위임 표현력

  • 🅓 initiator_kind 감사 열 — person/routine/handoff 구분 기록 + "아무도 안 볼 때" 필터. 무인 실행 신뢰의 핵심. audit_log 컬럼 추가(애드온)+queue 소스 전달. 공수 1일
  • 🅔 ask_person 도구 — 봇이 언제든 능동적으로 질문(도구 승인과 별개). 승인 카드는 "도구 허가"만 커버, "판단 질문"은 미커버. 공수 반나절
  • 🅕 위임 계약 타입화 — bot.delegate 인자에 task/bounds/definition_of_done 분리 + 실패 시 대화에 명시 보고. 공수 반나절
  • 🅗 루틴 쓰기 도구 — 봇이 "매주 월요일에…" 대화에서 스스로 create_routine. 공수 반나절

지금 만들지 말 것 (의도적 비대칭)

  • 다중 사용자·조직(people/roles/SCIM) — 단일 사용자 무키 철학과 충돌. 우리의 정체성은 "1인 AI 팀원 플랫폼"
